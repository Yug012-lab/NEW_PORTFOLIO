# Yug Verma — Portfolio 3000

> Cinematic full-stack developer portfolio with Three.js WebGL, PBR shaders, matte aesthetic & scroll storytelling.

## 🚀 Deploy on Vercel (3 steps)

1. **Push to GitHub**
   ```bash
   git init
   git add .
   git commit -m "initial: portfolio 3000"
   git remote add origin https://github.com/YOUR_USERNAME/portfolio.git
   git push -u origin main
   ```

2. **Import on Vercel**
   - Go to [vercel.com](https://vercel.com) → **New Project**
   - Click **Import** on your GitHub repo
   - Framework: **Other** (no build step needed)
   - Root directory: `./`
   - Click **Deploy**

3. **Live in 30 seconds** ✅
   - Your URL: `https://yug-verma-portfolio.vercel.app`

## 🎨 Tech Stack
- Vanilla HTML / CSS / JavaScript
- Three.js r128 (WebGL, PBR shaders, particles)
- Google Fonts (Syne, JetBrains Mono, Inter)
- No build step — pure static

- Custom PBR GLSL shader materials (matte polish)
